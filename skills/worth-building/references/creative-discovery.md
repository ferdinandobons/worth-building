# Generate better options

Use this when the need is unclear, the first proposed solution is getting all the attention, or work has stalled. One short session should end with options, an artifact, or a question to take back to the field.

## Prepare to start

- Choose a reliable starting action, such as opening the same working note and writing the question at the top. Put the materials in reach before the session and protect a short block from messages and other projects.
- Make a working folder with field notes, sketches, relevant examples, abandoned approaches, and observations from elsewhere. Annotate each item with what caught your attention and a question it raises. Keep source and permission details with material created by others.
- Name the useful result in one sentence. Ask, “What should someone be able to do or feel after this?” Use that sentence to decide what belongs in the work. Update it when evidence changes the problem.
- Notice where the builder sees details others miss and which skills or points of view are missing. Invite a collaborator or sample an unfamiliar workflow when a blind spot could change the work.
- If the starting point feels blank, recall three precise moments when the work mattered, went wrong, or looked unusually good. Collect a concrete detail from each and vary one. An unexpected result can become a useful option when you can explain what it changes for the audience.

## Gather and combine

1. **Look around the workflow.** Observe the step before and after the one that seems broken. Search analogous settings, work done under tighter constraints, and cases where the problem disappears. Separate what happened from the idea it sparks.
2. **Generate different responses.** Try a simpler procedure, a human handoff, an adaptation from another setting, or a product. Ask, “How would I get the same result without this feature?” and “What would I do if I could change one step?” Use a constraint such as one afternoon, one role, or an existing tool to make the options concrete.
3. **Build a small artifact.** Sketch a before-and-after flow, a paper screen, an example output, or a script for doing the job by hand. Let someone attempt the important step with a realistic input. Record where the artifact fails or creates another burden.
4. **Select against the purpose.** Compare how the options serve the desired outcome, what each assumes, and what can be learned next. Keep surprising ideas in the working folder with a reopening condition. Carry forward the option that earns the next check.

For a creative work with no commercial goal, choose a craft or audience outcome that fits the user's intent. A completed draft, clearer scene, or useful critique can serve that decision. Use the [evidence rubric](evidence.md) for any separate claims about demand.

## Get unstuck

Inspect the last few sessions. Is repeated work making output better, or is it reproducing the same weak result? If progress has stalled, change one input, constraint, sequence, collaborator, or medium and compare the next artifact. For a skill gap, isolate the weak move and practice it with feedback. For an unsupported premise, return to [problem discovery](opportunity-mapping.md). For a project that no longer fits, use [builder reflection](reflection.md).

After a failed attempt, record the expected result, what happened, and what to keep or change. A craft mistake, an inaccessible participant, and a false assumption call for different fixes. Finish one small attempt before adding a fresh direction if that is what will reveal the cause.
